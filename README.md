# Tiansi Zhu | Data Stories

Personal website and blog for ETC5523 Assignment 3, built with Quarto and published with GitHub Pages.

**Published site:** https://etc5523-2026.github.io/etc5523-assignment-3-tzhu0035-png/

## Intended audience

**Audience statement:** The blog post is written for curious members of the Australian public, such as people who travel or follow COVID-19 news, who have no training in epidemiology or statistics.

## Repository structure

| Path | Purpose |
|---|---|
| `_quarto.yml` | Site-wide settings: title, navigation, GitHub link, theme |
| `custom.scss`, `styles.css` | Custom theme (background, fonts, heading and link colours) |
| `index.qmd` | Blog listing (home page) |
| `about.qmd` | About page with photo, biography and links |
| `posts/delta-quarantine/` | Blog post source, bibliography and thumbnail |
| `docs/` | Rendered website served by GitHub Pages |

## How to rebuild

```bash
quarto render
```

The rendered site is written to `docs/`, which is committed so GitHub Pages can serve it (Settings → Pages → Deploy from a branch → `main` / `/docs`).
